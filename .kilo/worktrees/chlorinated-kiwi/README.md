# ems_gold

React 19 + Vite scaffold with a clear split of responsibilities for state.

## Stack

| Concern | Tool |
| --- | --- |
| Build | Vite 8 + `@vitejs/plugin-react` |
| Routing | TanStack Router (file-based, `src/routes/`) |
| Server state | TanStack Query |
| URL state | nuqs (`nuqs/adapters/tanstack-router`) |
| Client state | Zustand (`persist`) |
| Forms | React Hook Form + Zod (via `@hookform/resolvers`) |
| UI | shadcn/ui (radix base, `nova` preset) |
| Styling | Tailwind CSS v4 (`@tailwindcss/vite`, CSS-first config) |
| Animation | GSAP + `@gsap/react` |
| Lint | oxlint |

## Scripts

```bash
pnpm dev        # dev server on :5173
pnpm build      # tsc -b && vite build
pnpm typecheck  # types only
pnpm lint       # oxlint
pnpm preview    # serve dist/
```

## Layout

```
src/
  routes/            # file-based routes; routeTree.gen.ts is generated by the Vite plugin
    __root.tsx       # shell: nav, theme class, NuqsAdapter, Toaster, devtools
    index.tsx        # landing page, GSAP timeline via useGSAP
    tasks.tsx        # nuqs filters + Query list/mutations + RHF/Zod form
  features/tasks/    # schema.ts (Zod), queries.ts (queryOptions + key factory)
  components/ui/     # shadcn components (yours to edit)
  stores/ui-store.ts # Zustand: theme + density, persisted to localStorage
  lib/api.ts         # mock API — swap the bodies for fetch calls
  lib/query-client.ts
  router.tsx         # router instance + module augmentation for type-safe links
```

## Where state goes

- **URL** — anything shareable or reloadable (search, filters, pagination). `useQueryState` from nuqs. `/tasks` also declares `validateSearch` so `<Link search={{ priority: 'high' }}>` stays type-checked.
- **TanStack Query** — anything the server owns. Query keys come from the `taskKeys` factory; mutations invalidate `taskKeys.all`.
- **Zustand** — client preferences that outlive a route (theme, density).
- **React Hook Form** — in-flight form values, validated by one Zod schema that also types the submit payload.

## Adding things

```bash
pnpm dlx shadcn@latest add dialog dropdown-menu -y
```

New routes are files under `src/routes/` — the plugin regenerates `routeTree.gen.ts` on save. Note this registry version ships `field.tsx` rather than the older `form.tsx`; forms use `Field` / `FieldLabel` / `FieldError` with RHF's `register` and `Controller` (see `src/routes/tasks.tsx`).
